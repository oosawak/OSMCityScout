# 街並みスケッチ 3D × INKBOUND

**OpenStreetMap の地図データから街並みを 3D 生成し、その街を舞台に FPS「INKBOUND」を遊べるブラウザアプリです。**

初期地点は **山形県・山形駅西口**。検索した地名や緯度・経度へ移動でき、建物を選んで情報を見たり、写真を登録したりできます。ロケハン用のカメラ・線画表示・モデル書き出しと、INKBOUND の戦闘モードを同じ Three.js シーン上で切り替えます。

> **現在のバージョン：v0.8.1（試作版）**  
> 本 README は `index.html` v0.8.1 の実装内容に基づきます。街並みは測量済みの都市 3D モデルではなく、OSM の情報と推定形状を組み合わせて生成しています。

## 特徴

### 街並みスケッチ（ロケハンモード）

- OpenStreetMap / Overpass API から建物・道路・線路・樹木などを取得
- 建物の輪郭、高さ・階数、屋根、一部の窓・窓台・ベランダ・入口を 3D 化（不足情報は推定）
- 車道、歩道、道路の縁、中央線、横断歩道などを生成（一部推定）
- OSM の単木・並木のほか、公園・道路沿いの植栽を補完する機能
- 建物と線路の重なりを簡易的に補正（オン／オフ可）
- カラー／カラー＋線／線画／マンガ調の表示切り替え
- 俯瞰／近景／真上／目線カメラ、画角、背景色、陰影の調整
- PNG スクリーンショット、GLB 3D モデルの書き出し
- 10 文字のコードを用いた、サーバー登録不要の位置共有 URL

### 建物情報・写真登録・寸法編集・寸法編集（v0.8.1）

- **地図モード**で建物をクリックして選択・強調表示
- OSM に登録された建物名（`name:ja` / `name`）、用途、高さ、階数、住所、OSM ID を確認
- 名前が登録されていない建物には独自の表示名を保存可能（OSM 本体は変更しません）
- **建物の高さ（m）・階数を入力して保存**し、3D形状・窓配置・FPSの建物衝突判定に反映（「元の値に戻す」あり）
- 建物ごとに **正面・側面・背面** の写真を各 1 枚登録し、プレビュー・差し替え・削除
- 写真・表示名・高さ・階数はそのブラウザの **IndexedDB** に保存（利用できない環境では一時保存）

**未実装：写真から窓・外壁・建物モデルを自動解析／生成する機能。** 現在は、将来の自動生成に備えた写真登録機能までです。

### INKBOUND（FPS モード）

- 取得した街並みをそのまま戦闘ステージとして利用
- WASD 移動、ジャンプ、ダッシュ、スライド、グラップリング
- インクライフルによる射撃、リロード
- 追跡ドローンとの Wave 戦闘、HP、スコア、ゲームオーバーとリトライ
- 建物の壁・屋上の基本的な当たり判定、ドローンの回避処理
- 木の当たり判定：敵弾が木に命中すると **弾と木が両方消える**（再プレイ時に復元）
- 画面左下に建物・道路・プレイヤー・敵を示すミニマップ
- FPS 開始画面に検索先の地名を反映、FPS 専用の短縮共有 URL に対応

## 動かし方

### 最も簡単な方法

1. `index.html` を用意します。
2. PC の Chrome / Edge など、WebGL に対応した最新のブラウザで開きます。
3. 山形駅西口周辺の地図データが読み込まれたら、ロケハンを操作するか、上部の **「▶ INKBOUND FPS」** を押します。

HTML を直接開く `file://` 方式では、ブラウザによって外部 API や保存機能が制限される場合があります。確実に確認するにはローカル HTTP サーバーを利用してください。

### ローカルサーバー（Ubuntu / macOS / Python 環境）

```bash
# index.html のあるフォルダーで実行
python3 -m http.server 8000
```

ブラウザから **http://localhost:8000/** にアクセスします。

- Three.js は CDN から読み込むため、初回表示にインターネット接続が必要です。
- 地図情報の取得、地名検索、埋め込み地図も外部サービスへ通信します。
- インストール・ビルド処理は不要です（`index.html` が実行本体です）。

### GitHub Pages で公開

1. GitHub のリポジトリに `index.html` と本 `README.md` を追加してコミットします。
2. リポジトリの **Settings → Pages** で、公開元にブランチ（例：`main`）とフォルダー（例：`/ (root)`）を指定します。
3. 公開が完了すると、一般に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできます。

公開先 URL はリポジトリの設定によって異なります。**HTTPS の GitHub Pages を推奨**します。特別なバックエンドサーバーは不要ですが、外部の地図 API と CDN は利用します。

## 基本操作

### ロケハンモード

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | カメラを回転 |
| 右ドラッグ／2 本指 | カメラを移動 |
| マウスホイール／ピンチ | 拡大・縮小 |
| 建物をクリック | 建物名・OSM 属性・写真登録欄を開く |
| 「俯瞰」「近景」「真上」「目線」 | カメラ切り替え |
| 「この範囲を生成」 | 指定地点・半径で街を再生成 |
| 「PNG 画像」「GLB 3D」 | 書き出し |

**初期位置：** 北緯 `38.2485213`、東経 `140.3266479`（山形駅西口付近）  
**選択できる読み込み半径：** 180 / 280 / 450 / 650 m

### INKBOUND FPS モード（PC）

| 操作 | 内容 |
| --- | --- |
| WASD | 移動 |
| マウス | 視点操作 |
| 左クリック | 射撃 |
| Space | ジャンプ |
| Shift | 地上でダッシュ／空中でエアダッシュ |
| Ctrl | スライド |
| E 長押し | 建物を狙ってグラップリング |
| R | リロード |
| Esc | ポーズ（マウス固定解除） |

地図読み込み後に **「▶ INKBOUND FPS」→「▶ 戦闘開始」** の順で押します。ブラウザのセキュリティ制限により、FPS 専用 URL から開いた場合もマウス固定を開始するためのクリックが必要です。

## 共有 URL

地図モードの「**短縮URLをコピー**」、または「**FPS短縮URL**」で共有リンクを生成できます。INKBOUND の開始画面にも共有ボタンがあります。

```text
https://<公開先>/#g=<10文字のコード>
```

短縮コードには **緯度・経度（小数第 5 位精度）／読み込み半径／FPS モード指定** が含まれます。**地名の文字列自体は含まれません。** 別端末で開くと、座標から名称を逆引きするため、元の検索名と表示が異なる場合があります。

従来の `#ll=...&s=...&n=...` 形式も読み込めます。短縮コードはこのアプリ独自の方式であり、外部の URL 短縮サービスへの登録は行いません。

## 写真の保存について

- 写真はブラウザ内で長辺最大約 1,600px に縮小し、JPEG に変換して保存します。
- 取り込める写真は **1 ファイル最大 16MB**。ブラウザが読み込める画像形式に対応します。
- 登録名・写真・編集した高さ・階数は、**同じサイト・同じブラウザプロファイル**内でのみ参照できます。
- 建物の高さは **2.1〜600m**、階数は **1〜149の整数**で入力します。高さが未登録の場合は階数を使って推定します。入力内容はOSMには送信されず、モデル生成にのみ使用されます。
- 値を保存すると現在の3D街並みを再生成し、FPSモードの壁・屋上衝突判定も更新します。
- 「元の値に戻す」を押すとローカルの高さ・階数編集を削除して、OSM由来の値または推定値に戻します。
- **GitHub Pages や GitHub リポジトリへ写真を自動アップロードする機能はありません。**
- ブラウザのサイトデータを消すと登録内容が失われる可能性があります。現バージョンには写真データの一括エクスポート／別端末同期機能はありません。
- 写真登録はロケハンモードで行います。ゲームモード中のクリックは射撃操作です。

## 技術構成

| 項目 | 技術 |
| --- | --- |
| フロントエンド | 単一 `index.html`（HTML / CSS / JavaScript） |
| 3D 描画・ゲーム | Three.js / WebGL |
| カメラ | Three.js OrbitControls、FPS 用カメラ制御 |
| 3D 書き出し | Three.js GLTFExporter（GLB） |
| 街の基礎データ | OpenStreetMap、Overpass API |
| 地名検索・逆引き | Nominatim |
| サイト内保存 | IndexedDB（写真・表示名・建物の高さ・階数）、localStorage（地図キャッシュ等） |
| 配布 | 静的ファイル / GitHub Pages |

### データの流れ

```text
地名・緯度経度
   ├─ Nominatim（地名検索・逆引き）
   └─ Overpass API（OSMの建物・道路・線路・樹木等）
           ↓
     Three.js 街並み生成
        ├─ ロケハン：線画・カメラ・PNG / GLB
        ├─ 建物選択：OSM属性 + 写真登録 + 高さ・階数の上書き
        └─ INKBOUND：衝突判定・射撃・ドローン・Wave・ミニマップ
```

## 現在の制限・注意点

- **建物の実測 3D モデルではありません。** 高さが未登録の建物、窓、屋根、ベランダ、道路の細部、植栽の一部は自動推定です。
- OSM の登録状態によって建物名・階数・住所が出ない場合があります。
- 駅舎や線路、高架、屋上等の立体交差や衝突判定は完全ではありません。実際の建築・道路構造を保証しません。
- 写真からの 3D 自動生成、クラウド保存、写真や寸法編集の端末間共有は未実装です。
- FPS の操作はキーボード・マウスがある PC を想定しています。スマートフォンでのゲーム操作には未対応の部分があります。
- 公開 Overpass / Nominatim API は混雑・利用制限などで取得に失敗する場合があります。「地図データ取得先」を切り替えて再試行してください。大量・高頻度のリクエストは避けてください。
- 大きな読み込み範囲、植栽密度「多め」、建物ディテール「詳細」は描画負荷が高くなります。表示が重い場合は半径を小さくしてください。
